การผันเสียง (Tone Sandhi)
⭐ 3声
不 bù
一 yī
⚡ กรณีพิเศษ
⭐ กฎการผันเสียง 3+3 (สำคัญที่สุด!)
เสียง 3 ติดกัน 2 ตัว → ตัวแรกเปลี่ยนเป็น เสียง 2
แต่ เขียน pinyin เหมือนเดิม (สำคัญ! คนเรียนผันผิดบ่อย)
◌̌ + ◌̌ → ◌́ + ◌̌
ตัวอย่าง: 你好 เขียน nǐ hǎo → อ่าน ní hǎo
🎯 กฎการผันเสียงของ 不 (ไม่)
ปกติ 不 ออกเสียงเป็น bù (เสียง 4 — ตก)
แต่เมื่อตามด้วยคำเสียง 4 ต้องเปลี่ยนเป็น bú (เสียง 2 — ขึ้น)
bù + ◌̄ / ◌́ / ◌̌ = bù (เสียงเดิม)
bù + ◌̀ = bú (เปลี่ยนเป็นเสียง 2!)
🎯 กฎการผันเสียงของ 一 (หนึ่ง)
อยู่เดี่ยวๆ หรือท้ายคำ → yī (เสียง 1)
+ เสียง 1, 2, 3 → yì (เปลี่ยนเป็นเสียง 4!)
+ เสียง 4 → yí (เปลี่ยนเป็นเสียง 2!)
yī (เดี่ยว/ท้าย): 第一 dì yī
yī + ◌̄ / ◌́ / ◌̌ = yì (เสียง 4)
yī + ◌̀ = yí (เสียง 2!)
⚡ กรณีพิเศษ — 不 เป็นเสียงเบา
เมื่อ 不 อยู่ ตรงกลาง โครงสร้างพิเศษ จะออกเสียงเบา (neutral tone — bu)
A-不-A คำถาม: 是不是 → shì bu shì
เสริม "ทำไม่ได้": 看不见 → kàn bu jiàn

d t n ln, l ใช้กับ ü ได้ (nü, lü) — d, t ไม่ใช้กับ ü

j q xใช้กับ i และ ü เท่านั้น — เมื่อเจอ ü จะเขียน u (ju = jü)

z c sใช้กับ a / o / e / u — ไม่ใช้กับ ü — เสียง i พิเศษ (ดึงลิ้น)
